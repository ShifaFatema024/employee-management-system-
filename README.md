# Employee Management System

Yeh ek Employee Management System project hai jismein employees ka data manage kiya jata hai.

## 🚀 Features
* Employee details add, view aur manage karna.
* Python backend aur MySQL database integration.

## 🛠️ Tech Stack
* **Frontend:** HTML, CSS
* **Backend:** Python (Flask)
* **Database:** MySQL

## 💻 Setup aur Installation

### 1. Requirements Install Karein
Sabse pehle apne terminal ya command prompt mein niche di gayi command run karke Flask aur MySQL connector install karein:
```bash
pip install Flask mysql-connector-python
```

### 2. Database Setup
* Apne MySQL mein ek naya database banayein.
* `db_manager.py` file ke andar apna MySQL `host`, `user`, aur `password` sahi se set karein.

### 3. Project Run Karein
Sab setup hone ke baad, project ko chalane ke liye terminal mein likhein:
```bash
python app.py
```
Iske baad browser mein `http://127.0.0` open karein.
